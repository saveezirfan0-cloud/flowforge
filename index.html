🔑 Secrets Vault

Stored in your browser's localStorage — this device only, never sent anywhere.
How to use:
  1. Give each secret a name (KEY column, like AIRTABLE_PAT) and the value.
  2. Reference it anywhere — URL, header, body — as {{AIRTABLE_PAT}}.
  3. When you import a Make blueprint, Airtable modules arrive with Bearer {{AIRTABLE_PAT}} pre-filled, so just add the key here and you're set.
For the Unite → Airtable scenario, you'll want at minimum: AIRTABLE_PAT (from airtable.com → Developer Hub → Personal access tokens, with scopes data.records:read, data.records:write, and schema.bases:read for better error diagnostics) and UNITE_TOKEN (the Unite bearer token).
Special override: By default, FlowForge truncates datetime values to date-only when sending to Airtable (most Date fields don't accept time). If your Airtable date fields have "Include Time" enabled, set AIRTABLE_KEEP_TIME = true here.
